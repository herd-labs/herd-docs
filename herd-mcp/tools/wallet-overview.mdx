# Wallet Tools

Wallet Tools analyze EOAs, smart accounts, Safes, delegated accounts, and contract addresses using Herd's historical indexes.

<Info>
  Wallet Tools are available on fully indexed chains: **Base, Ethereum, and Monad**.
</Info>

## Available tools

| Tool | Use it to |
|---|---|
| `getWalletOverviewTool` | Summarize account type, balances, transaction counts, deployments, delegation, and Safe details. |
| `getTokenActivityTool` | Read a holder's current token balance and paginated incoming or outgoing transfers. |
| `getTransactionActivityTool` | Read enriched address activity with traces, balance changes, and contract creations. |

## Wallet overview

Wallet overview detects EOAs, ERC-7702 delegated accounts, ERC-4337 smart accounts, multisigs, and other contract wallets. Results can include token balances with USD values, activity totals, deployed contract counts, Safe signers and pending transactions, and delegation details.

## Token activity

Token activity returns a holder's current balance and up to 100 transfers per page. Each transfer indicates whether value moved in or out relative to the selected address.

The holder can be any valid EVM address, including a wallet, vault, token contract, or protocol contract.

## Transaction activity

Transaction activity returns decoded calls, traces, balance changes, and contract creations. Use caller mode for outgoing activity and callee mode for inbound or internal-call activity.

Query both directions and merge the results when you need a complete address history.

<Tip>
  Use [Transaction Tools](/herd-mcp/tools/query-transaction) to inspect one transaction in full after finding it in wallet activity.
</Tip>
