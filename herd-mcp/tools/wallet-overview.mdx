# Wallet Tools

<Warning>
  Wallet Tools require an Enterprise plan. To get access, contact [andrew@herd.eco](mailto:andrew@herd.eco).
</Warning>

Wallet Tools cover two connected workflows:

## Wallet intelligence

Analyze an EOA, smart account, delegated account, Safe, or contract address. Herd can summarize account type, token balances, historical activity, deployments, signers, pending Safe transactions, and ERC-7702 delegation details.

Historical wallet activity and aggregate balances are available on fully indexed chains: Base, Ethereum, and Monad.

## Agent wallet operations

Create shared groups with quorum rules and Herd-managed agent wallets. Link an agent wallet to an MPC-controlled wallet, prepare a HAL action, simulate it, collect approvals, and propose the resulting calls for human signing and execution.

For Safe integrations, Herd validates proposer access, proposal calls, simulation evidence, and group quorum. It can package multiple calls into one Safe transaction and track whether the proposal executes or becomes superseded.

The agent proposes; the destination wallet's owners or policy sign and execute. Herd does not bypass the wallet's threshold or custody controls.

## Typical flow

1. Read the group, agent wallet, and destination wallet context.
2. Reuse or create a HAL action.
3. Publish and simulate the action as the destination wallet.
4. Create a governed proposal from the simulated calls.
5. Collect group approvals and push the proposal.
6. Sign and execute in the Safe or MPC wallet.
7. Reconcile the proposal with its onchain execution.

<Info>
  Safe proposal support is available on a subset of registered EVM chains. See [Supported Chains](/herd-mcp/supported-chains) for the current list.
</Info>
