# Contract Tools

Herd combines verified source data, ABI analysis, proxy history, deployment records, and token metadata into agent-ready contract context.

## Available tools

| Tool | Use it to | Chain availability |
|---|---|---|
| `contractMetadataTool` | Read metadata, ABI signatures, function and event summaries, proxy history, deployment details, and token information. | Explorer-supported EVM chains |
| `getContractCodeTool` | Search verified source with a natural-language query or explicit regex patterns, or return the full source. | Explorer-supported EVM chains |
| `getDeployedContractsTool` | List contracts created by an EOA, factory, Safe, or another contract-based deployer. | Fully indexed chains |

`contractMetadataTool` follows proxy implementations and returns the complete known implementation history. Use its ABI before searching activity or building a HAL action.

`getContractCodeTool` accepts multiple addresses and can search implementation code, proxy code, or both. It only works when verified source is available.

`getDeployedContractsTool` covers direct creates, factory deployments, Safe deployments, and other traced creation paths. Results are paginated.

## Recommended workflow

1. Read the contract metadata and ABI.
2. Search the source for the behavior or permission you need.
3. On a fully indexed chain, inspect recent calls and event emissions.
4. Use the observed call patterns to build and simulate a HAL action.

<Note>
  Source-backed tools work on registered EVM chains with a configured code explorer. Polygon zkEVM, Sophon, and Swell are currently excluded.
</Note>

<Tip>
  For contracts on Base, Ethereum, or Monad, pair contract metadata with [Transaction Tools](/herd-mcp/tools/query-transaction) to see real parameter and approval patterns.
</Tip>
