# Collections

Collections group related actions and supporting adapters into a reusable workflow surface.

A collection can contain:

- Actions
- Read adapters
- Code adapters

Write adapters remain implementation dependencies and cannot be added as collection items.

## Available tools

| Tool | Use it to |
|---|---|
| `halSearchCollectionsTool` | Find your own or verified collections by name with pagination. |
| `halGetCollectionTool` | Read collection metadata, Herd links, and the published action or adapter items. |
| `halCreateCollectionTool` | Create a collection with actions and useful read or code context. |
| `halUpdateCollectionTool` | Change metadata or add and remove collection items. |

Collection results include direct Herd links for the collection and its visible items. Version history and full expressions remain on the individual action or adapter records.

## Design a useful collection

1. Add the executable action.
2. Add read adapters that explain current position or protocol state.
3. Add code adapters that calculate user inputs or expected outcomes.
4. Keep low-level write adapters as imports rather than visible collection items.

<Tip>
  A good collection gives an agent enough context to understand, parameterize, and simulate the action before proposing it.
</Tip>
