# Documentation Tool

| Tool | Use it to |
|---|---|
| `readDocumentationTool` | List or read Herd's built-in documentation resources by document ID. |

The documentation tool is the authoritative runtime reference for HAL syntax, modules, and worked examples. It can fetch one document or several documents in one call.

Important HAL document IDs include:

- `hal://spec/syntax`
- `hal://spec/modules/herd`
- `hal://spec/modules/object`
- `hal://spec/modules/array`
- `hal://spec/modules/math`
- `hal://spec/modules/types`
- `hal://spec/examples`

<Tip>
  Before an agent creates or changes HAL, have it read the syntax, Herd module, and examples documents in one request.
</Tip>
