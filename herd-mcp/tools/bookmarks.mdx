# Bookmark Tools

Bookmarks give an authenticated user or organization a reusable list of research objects.

## Available tools

| Tool | Use it to |
|---|---|
| `listBookmarks` | List bookmarks grouped by contract, transaction, wallet, action, collection, and protocol. Pass `objectTypes` to return only some groups. |
| `createBookmark` | Save a contract, transaction, wallet, action, collection, or protocol. Saving the same object again updates the existing bookmark. |
| `updateBookmark` | Change or clear the label on a contract, transaction, or wallet bookmark. |
| `deleteBookmark` | Remove a bookmark of any type. Removing a bookmark that does not exist succeeds. |

`createBookmark`, `updateBookmark`, and `deleteBookmark` take a `bookmark` object with an `objectType` field. The other fields identify the object:

| `objectType` | Identifying fields |
|---|---|
| `contract` | `contractAddress`, `blockchain` |
| `transaction` | `transactionHash`, `blockchain` |
| `wallet` | `walletAddress` |
| `action` | `actionId` (UUID) |
| `collection` | `collectionId` (UUID) |
| `protocol` | `protocolName` |

Contract and transaction bookmarks include a chain. Wallet bookmarks are chain-independent. `actionId` accepts both HAL actions and adapters.

## Labels

Contract, transaction, and wallet bookmarks carry a `userLabel`. When `createBookmark` gets no `userLabel`, or one that is only whitespace, Herd generates one from chain data. `updateBookmark` stores the `userLabel` you send, and `null` clears it.

## Saved functions and events

A contract bookmark can store saved functions and events in `details`. `createBookmark` replaces the stored ones with the `details` you send, and omitting `details` stores none.

<Tip>
  Call `listBookmarks` before `createBookmark` to see what is already saved. `createBookmark` fails with `BookmarkTargetNotFoundError` when the action or collection does not exist in your scope. `updateBookmark` fails with `BookmarkNotFoundError` when no matching bookmark exists.
</Tip>
