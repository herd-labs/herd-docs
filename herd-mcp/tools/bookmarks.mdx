# Bookmark Tools

Bookmarks give an authenticated user or resource scope a reusable list of research objects.

## Available tools

| Tool | Use it to |
|---|---|
| `getBookmarksTool` | List available bookmarks grouped by wallet, contract, transaction, action, collection, and protocol. |
| `updateBookmarksTool` | Add or remove bookmarks, and edit labels for wallets, contracts, or transactions. |

Contract and transaction bookmarks include a chain. Wallet bookmarks are chain-independent. Action and collection identifiers must be UUIDs.

Supported object types:

- Wallets, contracts, and transactions
- HAL actions and adapters
- HAL collections
- Protocols

<Tip>
  Read bookmarks before adding one to avoid duplicates. When no custom label exists, Herd returns a useful fallback display name when available.
</Tip>
