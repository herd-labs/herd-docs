# Herd Agent

Herd gives agents one interface for researching EVM activity, understanding contracts, simulating transactions, and preparing onchain actions.

Use Herd through its hosted MCP server or command-line interface. The available capabilities depend on your plan and the selected chain's indexing tier.

## Connect with MCP

Add the hosted server to an MCP client:

```bash
claude mcp add --transport http herd https://mcp.herd.eco/v1
```

Then open your client's MCP settings, select **Herd**, and complete the browser sign-in flow. Herd uses OAuth and does not require you to paste a token into your client.

<AccordionGroup>
  <Accordion title="Cursor">
    Add `https://mcp.herd.eco/v1` as a remote MCP server in **Settings → MCP**, then authenticate.
  </Accordion>
  <Accordion title="Codex">

  </Accordion>
  <Accordion title="Claude Code">

  </Accordion>
</AccordionGroup>

## Install the CLI

```bash
curl -fsSL https://raw.githubusercontent.com/herd-labs/herd-cli/main/install.sh | bash
herd login
```

`herd login` opens a browser for OAuth. The CLI stores its credentials in `~/.herd/credentials.json` with restricted file permissions.

## Choose the right chain tier

- **All registered EVM chains** support RPC-backed transaction inspection, HAL reads and simulations, and chain-aware bookmarks.
- **Fully indexed EVM chains** add historical activity search and aggregate wallet data. These chains are Base, Ethereum, and Monad.
- Some contract and wallet features have narrower capability requirements. See [Supported Chains](/herd-mcp/supported-chains).
