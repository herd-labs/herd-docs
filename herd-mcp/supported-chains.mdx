# Supported Chains

Herd separates **registered EVM support** from **full indexing**. A tool's chain parameter enforces the correct tier.

## Availability by tier

| Capability | All registered EVM chains | Fully indexed chains |
|---|---:|---:|
| Inspect a transaction by hash | ✓ | ✓ |
| Run HAL reads and simulations | ✓ | ✓ |
| Save chain-aware bookmarks | ✓ | ✓ |
| Read verified contract metadata and source | Most chains | ✓ |
| Search recent function calls and event logs | — | ✓ |
| Analyze wallet transactions, token activity, and deployments | — | ✓ |

<Note>
  Contract metadata and source search require an available code explorer. Polygon zkEVM, Sophon, and Swell do not currently support these features.
</Note>

## Safe support

Agent wallet proposals to Safe require Safe deployments and transaction-service support. Herd supports this flow on:

`arbitrum`, `avalanche`, `base`, `berachain`, `bsc`, `ethereum`, `hyperevm`, `ink`, `katana`, `linea`, `mantle`, `megaeth`, `monad`, `optimism`, `plasma`, `polygon`, `scroll`, `sonic`, `tempo`, `unichain`, `worldchain`, and `zksync`.

<Warning>
  Chain registration does not imply full historical indexing. Use the capability table above before choosing an activity or aggregate tool.
</Warning>
